# Labelling guide: <agent or workflow>, criteria <version>

For the experts. One page; keep it beside the traces while labelling.

## What you are judging

<One sentence: the task the agent performs and for whom.> Judge the whole
trace from the user's side: would you accept this <answer / decision> if a
colleague produced it with the same information?

## How to label

1. Read the trace in full: the question, the documents found, the actions
   taken and the answer.
2. For each criterion below, mark **pass** or **fail**. Fail means the
   failure described is present. There is no middle score.
3. On every fail, write one sentence saying what is wrong, in your own
   words. On a pass you hesitated over, write one sentence on why it
   passes.
4. When nothing in the list fits but something is wrong, mark the trace
   **other: fail** and describe it; new failure modes come from these notes.
5. Do not discuss traces in the overlap set with the other expert until
   both of you have labelled them.
