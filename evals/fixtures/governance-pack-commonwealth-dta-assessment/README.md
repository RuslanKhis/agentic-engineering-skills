# Claims triage assistant for the Compensation Claims Office

Southgate Labs (Sydney) is building a claims-triage assistant for the
Commonwealth Compensation Claims Office (CCO), a non-corporate Commonwealth
entity that handles compensation claims from former Commonwealth contractors
injured at work. The assistant reads a new claim and drafts a triage
recommendation (claim category, priority, missing evidence) that a claims
officer accepts or changes.
