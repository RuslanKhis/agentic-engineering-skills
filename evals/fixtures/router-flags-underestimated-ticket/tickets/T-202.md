# T-202 Connect each customer's Gmail so the assistant can read order emails

Requested by: Jon (product), 2026-10-24
Estimate: 1-2 hours of agent-assisted work
Pilot: 30 business customers, starting in three weeks

Pilot customers keep supplier order confirmations in their own Gmail. Let each
customer connect their Gmail account from the chat so the assistant can find the
confirmation for an order and answer questions about it.

- Each customer connects their own mailbox; nobody else may read it.
- They must be able to disconnect.
- Read-only access is enough (the assistant never sends from their mailbox).
- Our Google Cloud project for the pilot already exists; the OAuth consent screen has
  not been configured yet.
