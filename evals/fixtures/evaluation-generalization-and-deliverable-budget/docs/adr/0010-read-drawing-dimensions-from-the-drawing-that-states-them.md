# ADR 0010: Read drawing dimensions from the drawing that states them

Date: 2026-10-14
Status: accepted

## Context

The writer took the 4.2 m height on drawing 05 as the depth on drawing 03 and refused. (PA-2026-0203)

## Decision

Add a writer rule: quote each dimension with the drawing number it comes from.

Re-ran PA-2026-0203 on the new version: decision now matches the officer's label. Other development cases not re-run (cost).
