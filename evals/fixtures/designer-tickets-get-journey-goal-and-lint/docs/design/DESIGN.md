# Fenwick Mutual handler tools: design system

- Typeface: Inter, 14 px body, 20 px headings.
- Colours: primary #0B4F6C, surface #FFFFFF, muted #F2F5F7, danger #B3261E, success #1E7A46.
- Spacing scale 4 / 8 / 12 / 16 / 24 px; radius 6 px.
- Tables for queues: one claim per row, urgency as a coloured label with the word, never colour only.
- Every draft is labelled "Draft for review" until a handler accepts it.
