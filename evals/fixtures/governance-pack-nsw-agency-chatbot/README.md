# Public enquiries assistant for the NSW Trades Licensing Office

Southgate Labs (Sydney) is building a public enquiries chat assistant for the
NSW Trades Licensing Office, a NSW public sector agency that licenses
electricians, plumbers and builders. The assistant answers questions from the
Office's published guidance and lets a caller check the status of their own
licence application.
