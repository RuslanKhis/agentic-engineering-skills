# Discovery brief (extract): motor claims triage

- **Outcome measure:** share of claims triaged correctly with every required
  reason, as judged against the claims team's reviewed decision.
- **Baseline:** 61% for manual first-pass triage, September 2026.
- **Smallest lift the sponsor would act on:** 5 percentage points. The
  sponsor, the head of claims operations, has asked to hear only about
  changes of that size or more.
- **Evaluation budget:** about 600 agent runs per release for the holdout,
  both prompt versions together.
