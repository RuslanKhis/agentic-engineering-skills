# Shortlisting assistant for Kestrel

Southgate Labs (Sydney) is building a shortlisting assistant for Kestrel
Logistics B.V., a Rotterdam-based logistics company that hires warehouse,
driving and planning staff in the Netherlands and Germany. Recruiters upload
the CVs received for a vacancy; the assistant ranks them against the
vacancy's requirements and writes a short rationale per candidate.
