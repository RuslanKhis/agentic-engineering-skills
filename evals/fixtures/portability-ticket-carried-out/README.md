# Claims assistant for Tidewater Insurance

A policyholder-facing claims assistant built with Google ADK on Google Cloud
by Larkspur Digital for Tidewater Insurance. Policyholders check claim status,
add notes and upload photos; the assistant remembers what they told it in
earlier conversations and answers policy questions from the policy wordings.
