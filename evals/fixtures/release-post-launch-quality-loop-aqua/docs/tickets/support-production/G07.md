# G07 Weekly production quality loop

## Outcome

Each week someone (or something) looks at production quality, and failures that keep
coming back become eval cases (C6).

## Acceptance

- [ ] A1 WHEN a week ends THE release record SHALL show the quality review's result for that week (C6)
- [ ] A2 IF a failure recurs THEN THE eval set SHALL gain a redacted case for it (C6)
- [ ] A3 IF no review ran in a week THEN THE record SHALL say so (C6)

Verification, automated: none yet.
Verification, manual: Priya reads the first weekly record.
