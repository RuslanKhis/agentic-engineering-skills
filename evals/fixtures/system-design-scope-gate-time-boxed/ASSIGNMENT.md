# What to submit

1. Holdout predictions: for each of the five holdout cases, the decision, the reasons (citing local
   plan policies) and any conditions, as `predictions/<case>.json`.
2. The method: the code and a short description of how it works.
3. A report of at most two pages: approach, results on the development cases, limits.

Assessors (two planning officers and one engineer) read the report first, then the predictions,
then skim the code. Predictions are compared with the officers' real decisions and conditions.
Time guide: 3 to 4 hours.
