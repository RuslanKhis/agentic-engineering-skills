# Planning decision assignment

Take-home assignment for Brookfield District Council's planning service: an assistant that reads a
householder planning application's documents and the local plan, then drafts a decision (approve
or refuse) with reasons and conditions for a planning officer.

- `cases/dev/` five development cases, each with the officer's actual decision in `label.json`
- `cases/holdout/` five holdout cases without labels; the assessors hold their decisions
- `local-plan/` text extracts of the Brookfield Local Plan 2021 and the Householder Design SPD
  (the PDFs themselves are not in this folder; the extracts were made by hand and lose the
  figures)
- `ASSIGNMENT.md` what is submitted and how it is judged

Model allowance for the whole assignment: $25 of Gemini usage on the assessors' project.
