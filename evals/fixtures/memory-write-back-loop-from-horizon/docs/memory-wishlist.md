# What the assistant should remember (product owner, October 2026)

Engineers keep telling the assistant the same things every visit. We want it
to remember, per engineer:

- how they like answers (metric torque values, checklists instead of prose,
  language);
- kit they always carry (own harness, fibre splicer);
- things they have told it about a site that are their own notes ("I park on
  the lane, not in the yard").

Engineers share sites on a rota. One engineer's preferences or private notes
must never show up for another engineer, even on the same site. Some
engineers have said they do not want anything remembered about them, and the
works council has asked that people can see, correct and delete what is kept.

We have heard about a "Horizon" memory recipe that does the saving side
(flush, judge, consolidation); someone should look at whether we can use it.
