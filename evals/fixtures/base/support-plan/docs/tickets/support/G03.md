# G03 Honest failed replies

## Outcome

A reply that fails part-way keeps its partial text but is marked failed, never shown as final.

## Scope

- In: the message component's states (streaming, completed, failed, interrupted) and the failed
  badge.
- Out: retries.
- Depth: proof of concept.
