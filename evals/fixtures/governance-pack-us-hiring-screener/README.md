# Applicant screener for Redwood Freight

Southgate Labs (Sydney) built an applicant screener for Redwood Freight Inc.,
a freight and warehousing company headquartered in Oakland, California, with
warehouses in California and New York City. The screener scores applications
for warehouse associate and forklift operator roles and ranks them for
recruiters.
