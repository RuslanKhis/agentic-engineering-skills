# Specification: Northbridge IT helpdesk agent

Status: accepted 2026-09-30 (Owen, IT service owner)

## Purpose

Staff ask the helpdesk agent about laptops, accounts and VPN access. It
answers from the IT knowledge base, looks up the caller's open tickets and
raises new tickets.

## Users and identity

Northbridge staff only. Requests arrive through the intranet, which signs
each request; `app/app_utils/identity.py` verifies the signature and gives
the staff ID. The agent never takes a staff ID from the conversation.

## Tools

- `search_kb(query)`: IT knowledge-base articles.
- `my_tickets()`: the caller's open tickets.
- `raise_ticket(summary, category)`: a new ticket for the caller.

## Non-goals

- Changing anyone's account, password or access.
- Answering HR or payroll questions.

## Quality

Evaluation through `agents-cli eval` on `tests/eval/`; offline unit tests in
`tests/unit/`.
