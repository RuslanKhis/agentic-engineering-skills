# HR assistant for Érable Logistics

Southgate Labs (Sydney) built an HR assistant for Érable Logistics Inc., a
logistics employer with staff in Montréal and Toronto. Staff ask it HR policy
questions and submit leave requests through it; routine requests are
approved by the assistant.
