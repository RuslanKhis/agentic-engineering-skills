# G03 UI shell

## Outcome

Staff get a themed chat page: a conversation route, the chat column with streamed
answers and their sources, and honest states for failed replies.

## Scope

- In: shadcn initialised and themed from `docs/design/DESIGN.md`, a router with `/` and
  `/c/:conversationId`, the chat column reading `/api/chat` with fetch, message states
  (streaming, completed, failed).
- Out: conversation history sidebar (later), browser journey (G04).
- Depth: proof of concept; SB10 is built now (tier 1).

## Constraints

Identity, transport and stack as in AGENTS.md and the design; no user ID from the browser.

## Resources created

none

## Acceptance

- [ ] A1 WHEN a reply streams THE chat SHALL show text as it arrives and the completed state only after `completed` (C3)
- [ ] A2 IF the stream ends with `failed` THEN THE message SHALL keep its text and show the failed badge (C3)
- [ ] A3 WHEN a scripted reply contains an `<img onerror>` payload, a `javascript:` link and an image from an unlisted host THE chat SHALL render it inert and load nothing (C3, SB10)

Verification, automated: `cd web && npm run lint && npm test` exits 0; theme check exits 0.
Verification, manual: Lea checks the page against DESIGN.md in a browser.
