# Integration request from the dealer-portal team (2026-10-22)

They want to call our triage agent over A2A from their own orchestrator. Their
calls carry an OAuth 2.0 client-credentials access token issued by our
authorization server (`https://auth.service-desk.example`, audience
`warranty-triage`). They pin to the protocol version we publish and want to know
how we will version the card. Registration in any catalogue comes later and
needs its own approval.
