# Claims triage assistant

Larkspur Digital's engagement with Fenwick Mutual (a UK and Irish home and
motor insurer) to help claims handlers triage first notifications of loss.
The assistant drafts a triage recommendation (claim type, urgency, cover
position with the clause it relies on) that a handler accepts or changes.

Phase 1 (pilot, 14 handlers in Leeds) and phase 2 (production hardening and
the Dublin office) are complete. Go-live to all home-claims triage handlers in
Leeds and Dublin is planned for 2026-11-10.
