# Customer agent for Kowhai Retail

Southgate Labs (Sydney) built a customer chat agent for Kowhai Retail, an
outdoor and homewares retailer with stores and online customers in New
Zealand and Singapore. The agent answers order and returns questions, reads
the customer's order history from the CRM and can issue store credit up to a
limit.
