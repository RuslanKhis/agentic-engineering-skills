# system-design-scope-gate-time-boxed: what the fixture holds

Standalone overlay: README.md and ASSIGNMENT.md (deliverables: five holdout predictions, the
method, a two-page report; assessors are two planning officers and an engineer who read the report
first; 3-4 hours; $25 Gemini allowance), `cases/dev/case-01..05` (application, documents,
`label.json` with the officer's decision, reasons and conditions), `cases/holdout/case-06..10`
(no labels), and `local-plan/` text extracts of the local plan (H3, H4, T2, HE1, D5) and the
Householder Design SPD (Table 2, section 4). The PDFs are not present; the README says the
extracts were made by hand. Nothing in the workspace is code.

Assertion map: A1 scope gate first (time, money, who judges and what they read, artifact type =
assignment). A2 the core assessment path and a quality measurement on the five development cases
come first, with only a call budget and a stop as controls. A3 deferred controls named with
reasons; no officer revisions, export acknowledgement, saved-stage recovery or cloud roadmap as
early goals. A4 budget reserved to regenerate the holdout predictions with the final method; the
report names any mismatch between the method and the predictions. A5 plan proportionate to 3-4
hours; names what the reviewer reads (report, predictions, code). Only documentation may be
written; no implementation, installation or cloud.

Original context: "A greenfield workspace with five labelled development cases, five unlabelled
holdout cases, a local plan PDF pack and a $25 model allowance. The user authorizes local
documentation only. No implementation, installation or cloud actions are authorized."
