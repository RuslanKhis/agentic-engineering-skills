# Video description

## Suggested title

Google ADK Skills: Add Memory and a Frontend to Your Agent

## Description

Your Google ADK agent works. Now give it a frontend and memory.

This 2:20 walkthrough shows how to install Agentic Engineering Skills and ask
your coding agent to connect a React chat, stream replies, and remember a user's
preferred language between conversations.

Get the 12 free, open-source skills and copyable prompts:
https://github.com/RuslanKhis/agentic-engineering-skills

Use them with Claude Code, Codex or Google Antigravity. Client-specific setup
and commands are in the README.

This is an animated worked example, with real local code and test evidence.
Model responses and sign-in identities use offline doubles. The React code is
an integration excerpt. This is not a recording of a live coding-client session.

Runnable example and verification scope:
https://github.com/RuslanKhis/agentic-engineering-skills/tree/main/docs/video/skills-walkthrough/demo
