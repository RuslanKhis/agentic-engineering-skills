# T-201 Cancel an order from the chat (sales demo)

Requested by: Marta (sales), 2026-10-24
Time box: 3 hours, demo on Thursday

Sales wants to show prospects the assistant cancelling an order end to end. For the
demo, the assistant should be able to cancel one of the signed-in customer's orders
when they ask ("please cancel HO-10518").

- Use the orders team's staging API: `https://orders-staging.harbour.example/v2`.
  `POST /orders/{order_id}/cancel` with a bearer token returns
  `{"order_id": ..., "status": "cancelled", "cancellation_id": ...}`; 409 if the order
  has already shipped. Staging only holds fake orders (HO-9xxxx), reset nightly.
- The staging token is in the team 1Password vault under "orders-staging demo".
- Only orders that have not shipped can be cancelled (help article kb-101).
- If sales likes it, we will productionise it in a later ticket against the real
  orders API.
