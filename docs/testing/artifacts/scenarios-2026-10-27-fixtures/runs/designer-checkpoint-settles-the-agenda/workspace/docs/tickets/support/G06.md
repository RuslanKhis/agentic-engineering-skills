# G06 Forget is a hard delete

## Outcome

Forgetting a language removes the stored row and the cached session copy; nothing of the preference
is kept (D4, which rejects the soft-delete ruling recorded in G01).

## Scope

- In: replace the `deleted_at` soft delete and the 30-day purge with a row delete; read what
  `test_forget_clears_row_and_session_copy` really asserts and tighten it if it only checks that
  reads ignore the row; Priya's 0.5 h read of the forget path (moved from G01).
- Out: any retention window or support complaint view (needs a decision superseding D4).
- Depth: proof of concept; floor kept.
