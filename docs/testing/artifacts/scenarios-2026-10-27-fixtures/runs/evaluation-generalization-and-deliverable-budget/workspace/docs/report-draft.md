# Planning decision assistant: assessment draft

## Method

Each application runs source, writer, review and export stages (README). The workflow was
developed on five labelled development cases and changed through the decisions in `docs/adr/`.
The final version is v14, frozen on 2026-10-26 (`snapshots/v14/manifest.json`).

## Results on the development cases

All five development cases now produce the officer's decision on v14 (5 of 5).

## Limitations

- The "5 of 5" on the development cases is not a v14 measurement. Each case was last run on
  the version in which its fix was made (v9 to v14), and no version has been run on all five.
  Each fix was verified only on the case that prompted it, and the parking worked example
  (ADR 0013) was written from the case it was verified on. It shows that the fixes fit those
  cases, and it does not show how v14 performs on new applications or that later changes
  kept earlier fixes working.
- The only unseen cases are the five holdout cases. The deliverable on them comes from v9
  (see above), and we have no labels with which to score it.
- Five holdout cases, one sample each at temperature 1.0: results are too few and too
  variable to support a claim of improvement between versions.
- The data is synthetic (Eastmere Local Plan 2024) and covers four policy documents.
