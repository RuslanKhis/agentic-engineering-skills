# G01 Save and forget a reply language

## Outcome

A signed-in customer can save the language the assistant replies in, and forget it; later
conversations use it (D1).

## Scope

- In: a `preferences` table in the SQLite store, `GET/PUT/DELETE /api/profile/language` beside
  the existing profile routes in `app/profile_api.py`, keyed on the verified principal, loading the value into session state as `user:language` when a
  session starts, and the instruction reading `{user:language?}`.
- Out: streaming (G02), group or household preferences (out of scope for this release).
- Depth: proof of concept; floor kept (identity from IAP only, no secrets in code).

## Constraints

Identity comes from `app/auth.py` only (AGENTS.md); keep the existing tool interfaces.

## Resources created

none

## Acceptance

- [ ] A1 WHEN a customer saves a language THE app SHALL use it in their next session (C1)
- [ ] A2 IF another customer requests or deletes it THEN THE app SHALL return 404 (C1, SB01)
- [ ] A3 WHEN the customer forgets it THE app SHALL NOT use it in their next session (C2)
- [ ] A4 WHEN the service restarts THE saved language SHALL still apply to the customer's next session (C1)
