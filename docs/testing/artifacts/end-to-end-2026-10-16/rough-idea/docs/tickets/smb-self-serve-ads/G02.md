# G02 Local recommendation service

## Outcome
Given account, region and a sentence, code filters the catalogue, one `LlmAgent` (`gemini-3.8-flash`, pinned, `output_schema`) ranks one to three candidates with reasons, and validators enforce C1 and C3 (D1, D3). Runs locally against a catalogue fixture.

## Acceptance
- [ ] A1 a bakery sentence returns one to three products from the candidates with reasons (C1, C3)
- [ ] A2 an out-of-region id in model output is dropped; an injected instruction in the sentence changes nothing (C1)
- [ ] A3 invalid output: one repair, then the fallback (C4)
- [ ] A4 a reason naming no catalogue attribute is dropped (C3)
- [ ] A5 `max_llm_calls=2`; the ADK pin is confirmed (C4)

Verification: offline tests with a stubbed model.
