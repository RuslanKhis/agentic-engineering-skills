# Specification: Northbridge IT helpdesk agent

Status: accepted 2026-09-30 (Owen, IT service owner)

## Purpose

Staff ask the helpdesk agent about laptops, accounts and VPN access. It
answers from the IT knowledge base, looks up the caller's open tickets and
raises new tickets.

## Users and identity

Northbridge staff only. Requests arrive through the intranet, which signs
each request; `app/app_utils/identity.py` verifies the signature and gives
the staff ID. The agent never takes a staff ID from the conversation.

## Tools

- `search_kb(query)`: IT knowledge-base articles.
- `my_tickets()`: the caller's open tickets.
- `raise_ticket(summary, category)`: a new ticket for the caller.

## Proposed amendment: saved response language (pending Owen's acceptance)

- `set_response_language(language)`: saves the caller's reply language from a fixed allow-list
  (`app/preferences.py`) in ADK `user:` state (key `user:response_language`), which the Cloud SQL
  session backend keeps per staff ID across sessions and restarts. It is an exact setting, not
  semantic memory; no memory service is added.
- The instruction provider reads it on every invocation. Unlisted or free-text values are rejected.
- Open question for Owen: is the language list right, and should it be retained or erased with
  the staff member's leaving process? Until answered, the list is the 16 languages in the module and
  the value follows the session database's retention.

## Non-goals

- Changing anyone's account, password or access.
- Answering HR or payroll questions.

## Quality

Evaluation through `agents-cli eval` on `tests/eval/`; offline unit tests in
`tests/unit/`.
