# G01 Extract and qualify the policy corpus

## Outcome

A script turns `data/policies/*.pdf` into page records, an ingestion report and a document catalogue (ID, title, headings with pages) for the agent. Adds `pypdf` as the one new dependency. Implements D2, D4.

## Acceptance

- [ ] All ~30 PDFs appear in the catalogue with page counts.
- [ ] Scanned or low-density pages are listed as "not read", not silently dropped.
- [ ] Re-running produces identical output; no PDF content is committed.

Verification: offline, `pytest` on the extractor plus one run over the real folder.
