# T-202 Customers connect their own Gmail

Pilot customers should be able to connect their own Gmail account so the
support agent can read their order-confirmation emails when they ask about an
order. Each customer connects only their own mailbox and can disconnect it.
The pilot starts with 30 customers in three weeks.

## Evidence (2026-10-09)

Specialist: `adk-tool-auth-and-secrets` (delegated OAuth lifecycle branch).

Estimate check: the acceptance needs real Google consent, token exchange,
refresh, revocation, a token store and gateway routes. That work is 8–16 h,
and the restricted `gmail.readonly` scope also needs Google app verification,
which takes weeks. The 1–2 h estimate covers only the slice below. The rest
is in T-203.

Done (offline, with doubles for Google/Gmail only):
- `support_agent/gmail_connections.py`: owned connection index (principal,
  Google account `sub`, client, granted scopes, credential ref, status,
  revision); consent URL with PKCE S256, offline access, single-use
  10-minute state bound to principal and browser cookie; scope and client
  checks; omitted-refresh-token reuse only for same account/client;
  revision-checked publish; disconnect locally first, then revoke, then
  retire, with the revocation failure recorded; `invalid_grant` vs transient
  failure; fixed Gmail query, 5 messages, 300 chars per field, untrusted marker.
- `tools.read_order_confirmations(tool_context)`: no model-supplied identity,
  fails closed when not configured. Wired into `root_agent`.
- `support_agent/__init__.py` now imports `root_agent` lazily, so the tests
  run without the ADK SDK.
- `python3.11 -m unittest tests.test_gmail_connections`: 13 passed, 1 skipped
  (httpx not installed).

Not run: existing `tests/test_tools.py` and the tool-function test (httpx
absent); any ADK Runner/declaration check (google-adk absent); any real Google
OAuth or Gmail call.

Deliberately left out: the Google provider adapter, Secret Manager store,
persistent/shared index across Cloud Run replicas, access-token cache, gateway
connect/callback/disconnect routes, revocation reconciliation job (all T-203).
The exfiltration path (mail content plus `send_email` to any address) is for
T-104 before external customers use this.
