# G03 Check the agent against questions with known answers

## Outcome

A script runs 8–10 builder-labelled questions plus 3 out-of-scope ones through the ADK Runner and prints a table (question, answer, cited doc and page, match or not) for the builder to read. Implements D6. If time is short, shrink to five questions read by eye (see the design's cut line).

## Scope

- In: `gold.jsonl` (question, expected doc and page, or `expect: refuse`), runner with `max_llm_calls`, citation match check.
- Out: LLM judge, HR-expert labels (P2-1), CI.
- Depth: PoC. Floor: call cap on every run.

## Acceptance

- [ ] A1 WHEN the runner finishes THE runner SHALL print one row per question with the cited doc and page and whether they match the label (C1)
- [ ] A2 WHEN an out-of-scope question is asked THE agent SHALL decline and cite nothing (C1)
- [ ] A3 THE runner SHALL stop a run at the configured `max_llm_calls` (C4, floor)

Verification, automated: `python -m pytest tests/test_eval_check.py` exits 0 (the match check on canned answers); `python eval/run_eval.py` exits 0 and prints the table (live, uses model spend).
Verification, manual: builder reads the table and records the match count in the Evidence section.
