# G02 Ask a question in adk web and get a cited answer

## Outcome

`adk web` on loopback runs one `LlmAgent` with a read-only `search_policies` tool that answers with document and page, or says the policies do not cover it. Implements D3, D5. Takes the ADK pin and the model ID (from the dated lifecycle table in `adk-model-and-output-contracts`), and records both in AGENTS.md. The builder sets the spend cap (Q4).

## Scope

- In: agent, instruction, tool wrapper, pins, `.env.example`, offline tool tests.
- Out: gold set (G03), callbacks that block answers (P2-2).
- Depth: PoC. Floor: model ID pinned, key in environment only, spend capped.

## Acceptance

- [ ] A1 WHEN asked a question the PDFs answer THE agent SHALL reply with the answer and a document-and-page citation from that turn's search (C1)
- [ ] A2 IF search returns nothing relevant THEN THE agent SHALL say the policies do not cover it and not give an answer (C1)
- [ ] A3 THE agent SHALL NOT have any tool other than `search_policies` (C2)
- [ ] A4 THE model ID SHALL be a pinned constant and no key SHALL appear in source (C4, floor)
- [ ] A5 WHEN the spend cap is set THE builder SHALL have recorded where and its amount in AGENTS.md (C4, floor)

Verification, automated: `python -m pytest tests/test_agent.py tests/test_ingest.py` exits 0 (A3, A4; tool behaviour offline).
Verification, manual: builder asks one answerable and one unanswerable question in `adk web`, and confirms the cap exists (A1, A2, A5).
