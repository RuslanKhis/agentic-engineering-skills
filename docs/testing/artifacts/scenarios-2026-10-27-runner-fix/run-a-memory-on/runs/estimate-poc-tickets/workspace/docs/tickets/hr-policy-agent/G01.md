# G01 Search the HR policy PDFs by page

## Outcome

Running ingest over the PDF folder builds a page-level SQLite FTS5 index, a manifest and a coverage report; `search(queries)` returns doc, page and text. Implements D1, D2, D4.

## Scope

- In: config (PDF folder, db path), ingest, search function, offline tests on tiny synthetic PDFs.
- Out: the agent (G02); OCR; embeddings.
- Depth: PoC. Floor kept: PDFs, index and keys stay untracked.

## Acceptance

- [ ] A1 WHEN ingest runs over the folder THE ingest SHALL write a manifest row (file, sha256, pages, text pages) per PDF and one index row per page with text (C3)
- [ ] A2 IF a PDF has a page with no extractable text THEN THE ingest SHALL list it in the coverage report and exit non-zero unless it is in the exclusions file (C3)
- [ ] A3 WHEN searching a phrase known to be on one page THE search SHALL return that document and page in the top 3 (C1)
- [ ] A4 THE search SHALL NOT read any path outside the configured folder's index (C2)

Verification, automated: `python -m pytest tests/test_ingest.py` exits 0.
Verification, manual: builder reads the coverage report for the real 30 PDFs and records scanned files (Q1).
