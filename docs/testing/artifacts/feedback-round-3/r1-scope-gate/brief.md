# Assignment brief: planning assessment assistant

Build an assistant that reads a householder planning application (application
form, site plan, elevation drawings, any supporting statement) together with the
council's Local Plan and its supplementary planning documents, and drafts the
case officer's decision: approve or refuse, the reasons, and any conditions.

Materials supplied:

- Five development cases with the officer's actual decision, reasons and
  conditions (labels).
- Five holdout cases without labels. Your predictions for these are what we
  will score.
- The Local Plan (about 300 pages, PDF) and four supplementary planning
  documents (PDF). Some application drawings are scans.
- One model API key with a $25 allowance.

Time: 3 to 4 hours.

We will judge the submission on: the five holdout predictions; the method; and
a short report (under two pages) describing what you built, how you checked it,
and its limits.
