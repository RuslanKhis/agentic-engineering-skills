# G03 Show HR leadership the agent answering real policy questions on Friday

## Outcome

Ten gold questions (seven covered, one of them across two documents, and three out of corpus) are run through the agent into a reviewable table with a citation check, and a demo script with a fallback transcript is rehearsed once end to end in `adk web`.

## Scope

- In: gold file with expected doc and page written by the builder from the PDFs, runner, results table, demo script.
- Out: HR-reviewed labels and agreement (phase 2), CI gate.
- Depth: proof of concept. Cut order: 10 to 6 questions, drop the cross-document one.

## Resources created

Usage spend: the gold run, about ten questions, under the C5 cap.

## Acceptance

- [ ] A1 WHEN the runner finishes THE app SHALL write a table of question, expected doc and page, cited doc and page, and pass or fail (C1)
- [ ] A2 IF a cited doc or page was not returned by the tool in that turn THEN THE runner SHALL mark the question failed (C1)
- [ ] A3 WHEN an out-of-corpus question is asked THE agent SHALL answer with the not-found text and cite nothing (C3)
- [ ] A4 THE agent SHALL NOT state a policy fact in an out-of-corpus answer (C3)

Verification, automated: `python eval/run_gold.py` exits 0 and writes `eval/results.md`; failures are listed, not hidden.
Verification, manual: the builder rehearses `docs/demo-script.md` once through `adk web` and reads each failing row.
