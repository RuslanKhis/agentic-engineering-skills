# G01 Search the HR policy PDFs and get cited pages back

## Outcome

A script extracts every page of `data/policies/*.pdf` to JSON and reports empty pages; `search(query)` returns the top pages as `{doc, page, text}` (D1, D2, D6). First step: confirm the PDFs are text-based and the model use is approved (design questions 1-3), and pin dependencies and the model ID.

## Scope

- In: extraction, ingestion report, BM25 search, config paths, offline tests.
- Out: the agent (G02), gold questions (G03), scans and OCR (phase 2).
- Depth: proof of concept. Floor: no secrets in code; `data/policies/` git-ignored.

## Resources created

none

## Acceptance

- [ ] A1 WHEN ingestion runs on the sample PDFs THE app SHALL write one JSON record per page carrying doc name and page number (C1)
- [ ] A2 WHEN a PDF page yields no text THE app SHALL list it in the ingestion report and the search result for that document SHALL flag it (C4)
- [ ] A3 WHEN a known policy phrase is searched THE app SHALL return its page with the correct doc and page number (C1)
- [ ] A4 IF no page scores above the threshold THEN THE app SHALL return an explicit empty result (C1)
- [ ] A5 The pinned model ID and dependency versions are recorded in `pyproject.toml` or config (floor)

Verification, automated: `python -m pytest tests/test_ingest.py tests/test_search.py -q` exits 0.
Verification, manual: the builder opens the ingestion report and confirms it matches the real PDFs.
