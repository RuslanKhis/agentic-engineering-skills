# G02 Ask a question in adk web and get a cited answer or an honest not-found

## Outcome

An `LlmAgent` with the single tool `search_policies` runs in `adk web` on loopback with the pinned model, answers from returned pages with document and page citations, and declines when nothing supports an answer (D3, D4, D5).

## Scope

- In: agent, tool wrapper over G01 search, instruction file, model spend cap on the key or project.
- Out: gold-set scoring (G03), hosting and sign-in (phase 2).
- Depth: proof of concept. Floor: spend cap set, key in environment only.

## Resources created

none

## Acceptance

- [ ] A1 THE agent SHALL expose exactly one tool, `search_policies`, and no write, network or code tools (C2)
- [ ] A2 WHEN the query contains path text such as `../` THE tool SHALL search only the configured corpus and read no other file (C2)
- [ ] A3 WHEN the tool returns an empty result THE agent instruction SHALL direct the refusal text pointing to HR (C3)
- [ ] A4 WHEN `adk web` is started THE app SHALL bind to loopback only (floor)
- [ ] A5 The model spend cap on the key or project is set and the builder confirms it (C5)

Verification, automated: `python -m pytest tests/test_tools.py -q` exits 0 (SDK-tier cases reported as not run if the SDK is absent).
Verification, manual: the builder asks one covered and one uncovered question in `adk web`. The agent never ticks A5; its Evidence reads `manual: spend cap — confirmed by` the builder with the date, or `owed`.
